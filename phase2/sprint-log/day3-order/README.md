# 3日目（2026-11-24）：再生3パターン

## 追加したこと
- ツールバーに「再生の向き」を追加：順（崩れていく）／逆（元に戻っていく）／往復（崩れてから戻る）
- 「ぬるっと」の逆向きは、引き伸ばし量を記録した値から 0 へ少しずつ減らして再現する
- 往復は、いちばん崩れたところで少し止めてから戻る
- WebM の書き出しも、選んだ向きで再生しながら録る（ファイル名に向きが入る）
- 2日目の評価（ぬるっと ◎、0.15秒のほうがよい）に合わせて、開いたときの初期値を「ぬるっと・0.15s」にした
